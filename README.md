Một bản **clone Notion** được xây dựng bằng **React + TypeScript**, sử dụng **Vite** làm bundler, **shadcn + TailwindCSS** cho UI, **Redux** quản lý state, và **Vitest** cho testing.

---

## 📌 Tính năng

- Tạo, chỉnh sửa và xoá các trang (pages)
- Hỗ trợ nhiều loại block: text, heading, list
- Kéo & thả (drag & drop) block để sắp xếp
- Lưu trạng thái ứng dụng với Redux
- Giao diện responsive, đẹp mắt với TailwindCSS & shadcn
- Hỗ trợ dark mode (tuỳ chọn)
- Unit test với Vitest

---

## 🛠️ Công nghệ sử dụng

- **Vite** – Bundler siêu nhanh
- **React + TypeScript** – Frontend framework
- **TailwindCSS + shadcn** – UI đẹp, tiện lợi
- **Redux** – Quản lý state
- **Vitest** – Unit test
- **React DnD / Drag & Drop** – Sắp xếp block trực quan
- **ESLint + Prettier** – Code chuẩn & đẹp

## 💻 Cài đặt

1. Clone repository:

git clone https://github.com/username/notion-clone.git

2. Di chuyển vào thư mục dự án:

cd notion-clone

3. Cài đặt dependencies:

npm install

# hoặc yarn

4. Chạy ứng dụng:

npm run dev

# hoặc yarn dev

5. Mở trình duyệt và truy cập:

http://localhost:5173

6. 📝 Cách sử dụng

7. 🧪 Chạy test
   npm run test

# hoặc yarn test

Test được viết bằng Vitest
